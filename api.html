APIとは？

APIとは、プログラム同士がデータをやり取りするための仕組みです。
決められた形式で要求を送ることで、必要な情報を取得したり利用したりできます。
本DB内ではIDを入力し、キオクやポートレートのデータを取得することができます。

使い方

1. curlコマンドが実行可能な方

以下のコマンドをターミナルで実行してください。

curl -o [保存したい名前].json [url]

例（巴和葉のキオクデータを取得する場合）：

curl -o CHA0001.json https://scapetomoe.github.io/MadodoraDB/characters/CHA0001.json

2. curlがパソコンにインストールされていない方

Windowsの方

Windows 10（2018年頃以降）・Windows 11には標準でcurlが入っているため、通常は上記のコマンドがそのまま使えます。
「'curl' は、内部コマンドまたは外部コマンド...として認識されていません」と表示される場合は、代わりにPowerShellの機能を使ってください。

Invoke-WebRequest -Uri [url] -OutFile [保存したい名前].json

Macの方

macOSには標準でcurlが入っているため、ターミナルでそのままコマンドが使えます。

3. コマンドを使いたくない・使えない方

ブラウザだけでも取得できます。

  1. 取得したいデータのURL（例: https://scapetomoe.github.io/MadodoraDB/characters/CHA0001.json）にブラウザでアクセスする
  2. 画面に表示されたJSONデータの上で右クリック
  3. 「名前を付けて保存」を選択して保存する

保存せずそのまま画面上でデータを確認したいだけの場合は、URLにアクセスするだけで完了です。
